How each forecast is made

  1. Reads 11 years of Statistics Canada tables

    Hourly wages, shelter and all-items CPI by province, and employment by industry, 2014 to 2024. Last year's value and yearly growth become inputs.

  2. Scores both models on 2022 to 2024

    A linear regression and a 200-tree random forest learn from the years before 2022, then predict three years they never saw.

  3. Rolls the better model forward to 2027

    Each projected year feeds the next. The random forest adds a 90% range from the spread of its trees.

Questions

Built with Python 3.9 or newer, pandas, scikit-learn, Plotly and Streamlit.

Is this an official Statistics Canada forecast?

No. It is an independent model built on Statistics Canada open data. The figures are projections, not official estimates.

Which forecast does the dashboard show first?

The one with the lower error on 2022 to 2024. Linear regression won for all three indicators, so it leads; the random forest is one click away.

Why do the random forest forecasts flatten out?

Trees cannot predict values outside the range they trained on, so a series that keeps rising levels off.

Can I rerun the forecasts on new data?

Yes. Replace the two CSV files in data/ and run python src/train_models.py. It takes about 30 seconds.

Run the forecaster yourself

Clone the repository, install the packages and start Streamlit.
